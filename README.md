# Exercices Python — Programmation procédurale

Une série progressive d'exercices Python centrés sur la **programmation procédurale**.

## Objectif

Apprendre à résoudre des problèmes avec :
- variables et types ;
- entrées / sorties ;
- conditions ;
- boucles ;
- fonctions ;
- listes et dictionnaires ;
- manipulation de fichiers ;
- petits programmes complets.

Aucune classe ni programmation orientée objet n'est nécessaire.

## Progression

| Niveau | Thème | Exercices |
|---|---|---:|
| 01 | Variables et entrées | 5 |
| 02 | Conditions | 5 |
| 03 | Boucles | 5 |
| 04 | Fonctions | 5 |
| 05 | Listes et dictionnaires | 5 |
| 06 | Fichiers et projets | 5 |

## Conseils

1. Lis uniquement l'énoncé avant de coder.
2. Écris d'abord une solution simple.
3. Teste plusieurs cas, y compris des cas limites.
4. Refactore ensuite ton code avec des fonctions quand cela devient pertinent.
5. Ne consulte pas une correction avant d'avoir essayé sérieusement.

## Installation

Aucune dépendance externe n'est nécessaire.

Version conseillée : Python 3.11+.

## Lancer un exercice

Dans le terminal de VS Code :

```bash
python 01_variables_entrees/ex01_hello.py
```

ou, selon ton système :

```bash
python3 01_variables_entrees/ex01_hello.py
```

## Convention

Chaque fichier contient :
- un énoncé ;
- des objectifs ;
- un emplacement pour ta solution.

Les dossiers sont volontairement organisés par compétence pour rendre la progression visible sur GitHub.

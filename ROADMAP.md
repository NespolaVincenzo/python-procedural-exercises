# Roadmap

## Niveau 1 — Fondations
Variables → input() → conversions → calculs.

## Niveau 2 — Décisions
if / elif / else → opérateurs logiques → conditions combinées.

## Niveau 3 — Répétition
for → while → accumulateurs → break → recherche algorithmique.

## Niveau 4 — Modularité
def → paramètres → return → fonctions booléennes → menus.

## Niveau 5 — Données
listes → dictionnaires → recherche → filtrage → statistiques.

## Niveau 6 — Programmes complets
fichiers → menus → persistance → petits projets en ligne de commande.

### Règle de progression

Ne passe au niveau suivant que lorsque tu peux résoudre la majorité des exercices
du niveau actuel sans recopier une solution.
